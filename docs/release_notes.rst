ダウンロードメソッドの名前変更
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
ダウンロードするファイル形式が分かるように、``Wrapper`` に
``download_annotation_zip`` と ``download_project_*_json`` の計6メソッドを追加しました。
引数、戻り値、ダウンロード処理は従来と同じです。

対応する旧メソッドは非推奨となり、呼び出し時に ``FutureWarning`` が発生します。
旧メソッドは2027-04-01以降に削除予定です。
移行先の一覧は :doc:`user_guide/advanced_usage` を参照してください。
